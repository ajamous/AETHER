# Learn RSP

Telecom is a small industry with a small published learning canon. The GSMA
specs are excellent reference material but heavy reading if you're new.
This section is meant to be the gentle on-ramp the field is missing.

We assume you can read documentation written for engineers, but we do not
assume prior telecom experience.
