# Aether

Open Source Remote SIM Provisioning for the Open Telecom Era.

This documentation site is the long-form companion to the
[repository on GitHub](https://github.com/ajamous/aether). The README is
the source of truth for project status; this site is the source of
truth for *how things work* and *how to operate them*.

## Where to start

- **Curious engineer?** Start with [Quick start](quickstart/index.md)
  to bring up a local lab, then read
  [How RSP actually works](learn/how-rsp-works.md).
- **MVNO or carrier evaluating Aether?** Start with
  [Architecture](architecture/index.md), then
  [Deployment](deployment/index.md), then
  [SAS-SM readiness](sas-sm/index.md).
- **Standards-focused contributor?** Read the
  [SGP.22 coverage matrix](standards-compliance/sgp22-matrix.md) and
  the [ADRs](architecture/adr/index.md).

## What this site is not

It is not marketing material. It is not a sales site. It will not tell
you that Aether is "world-class" or "industry-leading," because we don't
believe in saying things about our own work that we haven't earned.

What you will find: the architecture, the protocols, the threat model,
the operational runbooks, the deployment topologies, and a candid
record of every significant decision we've made and why.

## Contributing

See [CONTRIBUTING.md](https://github.com/ajamous/aether/blob/main/CONTRIBUTING.md)
in the repository. The short version: sign your commits with
`git commit -s`, open a focused PR, expect one maintainer review.
