## Becoming a maintainer

See [GOVERNANCE.md](GOVERNANCE.md). Sustained contributions, sound
judgment on issues and PRs, and the trust of existing maintainers are
the criteria. There is no formal application process; if you've been
contributing for a while and would like to be considered, ask any
existing maintainer.
